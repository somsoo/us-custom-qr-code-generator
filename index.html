🧮 How the code is built

    
    
      
  • Encoding: digits only use numeric mode, text made only of 0–9, A–Z, space and $ % * + - . / : uses alphanumeric mode, and anything else is stored as UTF-8 bytes. The smallest version (1 to 40) that fits at your error correction level is chosen.
    • 
      
  • Error correction: Reed-Solomon codewords are added per ISO/IEC 18004, then the tool tries all 8 mask patterns and keeps the one with the lowest penalty score.
    • 
      
  • Content formats: Wi-Fi networks use WIFI:T:…;S:…;P:…;; with \ ; , " and : escaped by a backslash; contacts use a vCard 3.0 card; email uses a mailto: link and phone a tel: link.
    • 
      
  • Downloads: the PNG uses a whole number of pixels per module, so it can be a few pixels under the size you pick; the SVG is vector and scales without blurring.
    • 
      
  • Size tips: DENSO WAVE says phone cameras read about 271 bytes (version 10, level L) reliably, though this varies by phone, so keep content short.
    •

❓ Frequently asked questions

    
Is it free to use QR Codes?
Yes. DENSO WAVE, which developed the QR Code, says no application or fee is needed as long as the code follows the JIS or ISO standard. This tool builds codes by the ISO/IEC 18004 rules. QR Code is a registered trademark of DENSO WAVE INCORPORATED.

    
Which error correction level should I choose?
Level M is the usual choice: DENSO WAVE notes that it restores about 15% of the codewords and is the level selected most often. Levels Q and H survive more dirt and damage but make the code denser, and adding a logo switches the code to H.

    
Can I put a logo in the middle?
Yes. The logo covers about 15% or 20% of the code's width, sits on a patch of the background color, and error correction is set to High. DENSO WAVE warns that covering part of a code can make it slow or impossible to read, so scan it with a few phones before you print.

    
How does a Wi-Fi network code work?
It uses the WIFI: format documented by the ZXing project, which the built-in cameras on Android and iOS 11 and later can read. It holds the network name, password and security type, so anyone who scans it can join the network. Your details stay in your browser.

    
Which colors and margin are safe?
Dark modules on a light background with strong contrast scan best. DENSO WAVE recommends black on white and warns that scanners using red light cannot read a red code on white. Keep a quiet zone of 4 modules around the code.

  


  

    
⚠️ Please note

    
Always scan a code with more than one phone before printing it, especially with colors or a logo. A Wi-Fi code contains your password in plain form, so share it only with people you would give the password to.
